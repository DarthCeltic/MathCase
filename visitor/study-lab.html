Scoring rule

A planned slot is one frozen case in one arm. A slot counts as a reported pass only when exactly one non-conflicting v2 envelope binds the exact frozen manifest SHA-256, study, case, arm, problem, exact statement hash, and a run summary saying solved=true with an attempt reporting PASS plus a proof hash. Older or stale envelopes remain descriptive and never count toward matched scoring. Missing, malformed, duplicate, or conflicting inputs remain visible and do not inflate the denominator.

This is an accounting rule over user-supplied records. The report labels results as reported fields; a proof hash alone is not a Lean kernel receipt or an authenticated run.
