Teach with MathCase, locally or by file.

Use the file handoff below for a no-server classroom, or run the optional self-hosted service for separate teacher and learner accounts with assignments saved on your own machine.

Self-hosted option: the Go prototype listens on your computer only by default. It stores accounts, assignments, and submissions in a local data directory. It does not send work to MathCase, check Lean proofs, or create evidence receipts. Read the setup and security limits before using it. Do not expose it to the public internet.
