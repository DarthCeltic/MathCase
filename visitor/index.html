Check the proof

Add the exact proposition and its declaration name to check that the theorem proves the target.

Before running: review the Lean code. It is sent to the public Lean editor, along with the generated target check when available. That service chooses its Lean/Mathlib version, which may differ from MathCase's pinned Lean 4.33.1 local checker. The editor shows compiler output; it does not create a MathCase receipt.

Prefer a separate window?

The editor opens here. Press its Run control to check the code. Copy any edits back into this workbench to save them.

If it says “No connection to Lean” or stays on “Updating…”, the online checker has not checked your proof. Choose Reconnect from draft to reload the code currently in this workbench. Copy any changes from the editor back here first. If it still cannot connect, use the pinned local check below.

Check locally and save a receipt

First choose Export full case. That saves a JSON packet with the claim, exact proposition, theorem name, and Lean source. Place that packet in the MathCase checkout and run the command below. The starter example uses Lean Core. If your file imports Mathlib, use a Lean 4.33.1 project where Mathlib is already installed and add --lake-project PATH to the command.

To run this in a MathCase Codespace, open its terminal and use the command below. The Codespace provides Lean Core; it does not download Mathlib for you.
