# MathCase math-results package

This folder is a public, source-backed overview of selected MathCase math work. Start with [the full evidence atlas](../../docs/MATH_RESULTS.md) and [the research-system roadmap](../../docs/MATHCASE_RESEARCH_ROADMAP.md).

Included in this branch:

- M15, M16, M18, and M20 Collatz Lean source and finite scan inputs.
- Selected M29/M31 affine-family Lean sources.
- The frozen 4,096-class M31 residual sample and the exact finite valuation audit.
- The Egyptian–Straus identities, bounded witness data, and local exact checkers.
- A release manifest that hashes the included public files.

This is not a MathCase standard M4 acceptance package. The historical M15–M20 machine receipts remain outside this public branch, and this publication did not recompile Lean. The M21–M31 aggregate scan data and private run archive are also not included. Read each limit in the atlas before citing a result.
